# プライバシーポリシー

制定日: 2026年7月21日
最終更新日: 2026年7月21日

「ともにつくるAI」(以下「当方」)が提供するWindowsデスクトップアプリケーション「AIヘルプキャプチャ」(以下「本アプリ」)における、利用者情報の取り扱いについて、本ポリシーで説明します。

## 本アプリの概要

本アプリは、利用者がWindows上で行った操作(画面キャプチャ、マウス操作、キーボード操作)を記録し、AI(ChatGPT、Claudeなど)へ相談しやすい形の画像にまとめるためのデスクトップアプリです。生成した画像は、利用者が自分の手でAIサービスの入力欄へ貼り付けて使用します。

## 取得する情報

本アプリは、利用者が画面上の「記録開始」を押してから「記録停止」を押すまでの間のみ、以下の情報を**利用者の操作端末上でのみ**取得します。バックグラウンドでの常時取得や、記録操作なしでの自動取得は行いません。

1. **スクリーンショット画像**
   利用者が指定した画面範囲(モニター全体、または自由選択した矩形)を、一定間隔または操作をトリガーに撮影した画像です。
2. **マウス操作履歴**
   左/右クリック、ダブルクリック、ドラッグ、ホイール操作について、操作の種類と画面上の座標を記録します。既定でオンになっており、設定でオフにできます。
3. **キーボード操作履歴**
   押されたキー(修飾キー込みの表示ラベル。例: 「Ctrl + S」「w」)を記録します。既定はオフで、利用者が設定でオンにした場合のみ取得します。
   記録中に入力したキー操作がそのまま記録されるため、パスワードなど機微な情報を入力する操作を記録しないようご注意ください。
4. **アプリ設定**
   キャプチャ頻度、記録対象、画質プリセットなど、動作に関する設定値です。個人を特定する情報は含みません。

## 保存場所

取得したデータは、すべて利用者のPCのローカルストレージにのみ保存されます。

| 内容 | 保存先 |
|---|---|
| スクリーンショット・相談用の結合画像 | `%LOCALAPPDATA%\TracePrompt\Temp` |
| アプリ設定 | `%LOCALAPPDATA%\TracePrompt\settings.json` |

## 外部送信の有無

本アプリには、取得した情報をインターネット経由で外部のサーバーへ送信する機能は一切実装されていません。本アプリ自体に通信(ネットワーク)処理は含まれていません。

生成した画像は、利用者自身がクリップボード経由でChatGPTやClaudeなど外部のAIサービスへ貼り付けて利用することを想定しています。この送信は利用者本人の操作によって行われるものであり、本アプリが自動的に送信することはありません。貼り付け先のAIサービスにおける取り扱いには、それぞれのサービスのプライバシーポリシーが適用されます。

## クリップボードへのアクセスについて

本アプリは、生成した画像やテキストをクリップボードへコピーする機能、および現在クリップボードにコピーされている内容をアプリ内で確認表示する機能(貼り付け結果を確認するためのプレビュー)を持ちます。これらはすべて利用者の操作端末内で完結し、外部へ送信されることはありません。

## データの削除方法

- 記録した操作履歴・キャプチャ画像・相談用データは、アプリ画面の「記録データを今すぐ削除」ボタンからいつでも削除できます。
- 本アプリを終了すると、記録データ(上記の保存場所にあるスクリーンショットや相談用画像などのファイル)は自動的にすべて削除されます。また、次回起動時にも、前回終了時に残っていたデータを自動的に削除します。
- アプリ設定(`settings.json`)は、アンインストール時に自動削除されない場合があります。完全に削除したい場合は、`%LOCALAPPDATA%\TracePrompt` フォルダを手動で削除してください。

## 第三者への提供

本アプリは、取得した情報を第三者へ提供・販売することはありません。
