# AIヘルプキャプチャ

AIヘルプキャプチャ は、Windows 上の操作を記録して、AI に相談しやすい形へまとめるためのデスクトップアプリです。
指定した画面範囲のスクリーンショットと操作履歴を集め、各コマに操作内容の説明を書き込んだ結合画像として整理できます。

生成した画像を、ChatGPT や Claude などの入力欄へ手動で貼り付けて使います。

## できること

- 画面範囲(モニター全体、または自由選択した矩形)を指定して、操作中のスクリーンショットを記録できます。
- マウス操作やキーボード操作を履歴として残せます。
- 記録した内容を、各コマに操作内容の説明を書き込んだ結合画像にまとめられます。
- 生成した画像をクリップボードへコピーし、そのまま AI に貼り付けられます。
- キャプチャ枠の小さなツールバーから、開始・一時停止・再開・停止を操作できます。

## 動作環境

- Windows 11
- .NET 8 SDK


## 使い方

1. アプリを起動します。
2. キャプチャ範囲を選びます(全画面ならモニターを選択、自由選択なら画面をドラッグして矩形を指定)。
3. `記録開始` を押します。
4. 対象アプリを操作します。
5. 記録を止めると、相談用画像が自動生成され、画像コピーまで完了します。
6. 生成された画像を AI の入力欄へ貼り付けて相談します。

## キャプチャ方法

AIヘルプキャプチャ には 2 つのキャプチャ方法があります。

- `時間でキャプチャ`
  指定した頻度で連続してスクリーンショットを記録します。
- `操作でキャプチャ`
  指定したキーまたはマウス操作が行われたときだけスクリーンショットを記録します。

## 記録中の操作

記録中は次のような操作を扱えます。

- 左クリック / 右クリック
- ダブルクリック
- ドラッグ
- マウスホイール
- キーボード入力

必要に応じて、マウス操作とキーボード操作の記録を個別に切り替えられます。

## 出力される内容

記録後は、主に次の内容を利用できます。

- スクリーンショットをまとめた結合画像(各コマに操作内容の説明が書き込まれています)
- 画像コピー結果の確認
- 記録中に保存された元画像

画像はクリップボードへコピーできるので、そのまま AI に貼り付け可能です。

## 保存先

一時ファイルは次の場所に保存されます。

```text
%LOCALAPPDATA%\TracePrompt\Temp
```

キャプチャ枠のツールバーにある `フォルダを開く` から、この保存先をすぐ開けます。

## 補足

- 一時停止・再開はキャプチャ枠のツールバーから手動で操作します(自動では一時停止・再開しません)。
- 記録停止後も、必要に応じて生成結果の確認や再コピーができます。
- 設定はローカルに保存され、次回起動時にも引き継がれます。
